# Memory

## Active Projects
- **Dr. Chris Kiptoo Website**: Creating a personal professional website for Dr. Chris Kiptoo, CBS.

## Key Decisions
- **Design Language**: Follow institutional/governmental standards. Typographical choices: Georgia headings, Calibri body. Color palette: Deep Navy (#0F1B2D) for main identity, Teal (#00869B) and Gold (#C09E5A) for accents, off-white/cream backgrounds for clean contrast. No gradients, glassmorphism, or modern animation slop.
- **Technology Stack**: Standard HTML, vanilla CSS, and vanilla JS. Fully responsive and accessible.
- **Portfolio Consolidation**: Consolidated the three separate portfolio pages (Treasury, Trade, Environment) into a single, unified `portfolios.html` page using deep in-page navigation anchors (`#treasury`, `#environment`, `#trade`) to provide a cohesive, complete record of public service in one location. Set legacy files to auto-redirect.
- **Kenyan Flag Hero Background**: Waving Kenyan flag background on `index.html` softened with a high-transparency overlay to act as a watermark, maintaining text readability.
- **Authentic Media Gallery**: Overhauled the gallery to replace desaturated placeholders with unique photos and authentic, detailed captions extracted from `manifest.json`.
- **Social Media & Footer Standardization**: Standardized footers across all HTML pages to use a consistent 4-column layout with verified social/official links: X/Twitter link to `@Kiptoock`, official National Treasury website link, and an internal mail contact link.
- **Contact Us Redesign**: Simplified `contact.html` by replacing the photo hero with a forest-green banner displaying an inspiring stewardship quote from Dr. Wangari Maathai and centering the correspondence form while removing all address/board text blocks.

## Known Issues
- None.

## Lessons Learned
- Integrating authentic public record data (scraped manifests) directly into the website's captions provides significant credibility and premium context compared to generic placeholder copy.
